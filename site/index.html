WHAT IT DOES

One bridge, several workflows.

DroidWebDisplay keeps the Android device as the compute endpoint while the PC provides the larger screen, keyboard, mouse, and file workflow.

▣

Physical & virtual displays

Mirror the physical Android screen or create a separate virtual display with its own workspace.

⌁

Browser control

Use pointer and keyboard input from the browser through the local DroidWebDisplay bridge.

↔

File transfer

Move files between the PC and Android storage, with transfer and folder-sync workflows.

▦

App relocation

Inspect running apps and move supported activities onto the selected Android display.

◉

Desktop host

Run the service through the desktop host on Windows or Linux, then open the local web interface.

⌾

Controlled LAN access

Local access is the default; optional trusted-network access is documented separately with authentication and HTTPS guidance.

GET STARTED

From phone to browser in three steps.

  1. 01

    Install DroidWebDisplay

    Download the latest packaged release for your host platform, or install from source for development.

  2. 02

    Connect Android

    Enable Android developer options and USB debugging, then authorize the host when prompted.

  3. 03

    Launch the web UI

    Start the host service and open the local DroidWebDisplay interface in a supported browser.
