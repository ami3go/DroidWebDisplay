## Build and release dependency inventory

Release CI also produces machine-readable evidence for the dependency set used to validate and build DroidWebDisplay:

- `build-sbom.cdx.json` — a CycloneDX build SBOM covering the resolved Python environment, npm lockfile packages, pinned GitHub Actions, pinned external build artifacts, and the pinned scrcpy server.
- `license-inventory.json` — a companion inventory of package names, versions, ecosystems, declared license metadata, package URLs when available, and their source records.

The files are generated by `tools/generate_sbom.py` and uploaded by the release gate as the `supply-chain-evidence` workflow artifact. They complement these human-maintained notices; they do not replace upstream license texts or the licensing terms that apply to redistributed third-party binaries.

External build-tool identities and checksums used by CI are recorded in `packaging/supply-chain-lock.json`. Downloads made by the hardened CI path are rejected if their SHA-256 digest (and, for Android Platform-Tools, the embedded revision) does not match the lock.
